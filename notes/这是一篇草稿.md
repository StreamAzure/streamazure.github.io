这篇笔记的 front matter 里写了 `draft: true`。

**它不会出现在站点上。** 发布用的构建命令不带 `--buildDrafts`，所以 Hugo 会直接跳过它。

它的用途是：

- 写到一半的想法可以先 push 保存，不用担心被看到
- 想预览草稿的样子时，去 GitHub 的 Actions 页面手动跑 **Preview** 工作流，会产出一个包含草稿的站点压缩包供下载，但**不会发布上线**

写完了想发布，就把这一行 `draft: true` 删掉（或改成 `false`），再 commit + push。
